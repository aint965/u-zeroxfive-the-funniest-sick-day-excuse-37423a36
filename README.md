A make.fun entry for [The Funniest Sick-Day Excuse](https://make.fun/bounty/u-zeroxfive-the-funniest-sick-day-excuse-37423a36): a program that writes one line — the funniest sick-day excuse you can send in a single breath — to `/output/entry.txt`.

Run it with `node main.ts` (Node 22). The output directory is `process.env.OUTPUT_DIR` when set, otherwise `/output`.
